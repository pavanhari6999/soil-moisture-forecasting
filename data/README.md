# Data provenance

## Source dataset

**AgriDataValue – Environmental Data Useful for Smart Irrigation**  
Zenodo DOI: https://doi.org/10.5281/zenodo.18959383

Four station-year datasets are covered:

| Dataset | Year | Crop |
|---|---:|---|
| Station 34 | 2024 | Sorghum (Jumbo Star) |
| Station 35 | 2024 | Corn (Forturio) |
| Station 34 | 2025 | Corn |
| Station 35 | 2025 | Corn |

Raw observations: **22,111**  
After documented quality control: **22,050**

## Redistribution

The original AgriDataValue files are not included here because the current Zenodo record does not state an explicit redistribution license. Download the original data directly from Zenodo.

Do not commit the original raw files to this repository unless redistribution permission is confirmed.

## Variables

The study uses soil moisture, air temperature, air humidity, air pressure, dew point, precipitation, soil temperature, lagged variables, precipitation aggregates, and cyclical temporal features.

See the manuscript for the exact feature definitions, quality-control rules, forecasting horizons, validation protocol, and statistical analysis.
