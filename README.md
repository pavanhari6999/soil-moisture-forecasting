# Beyond Persistence: Soil Moisture Forecasting

Reproducibility repository for **Beyond Persistence: A Chronological Benchmark of Machine Learning for Short-Term Soil Moisture Forecasting Across Station-Year Datasets**.

**Author:** Daggumati Pavan Hari Krishna  
**Affiliation:** Department of Computer Science and Engineering, K L Deemed to be University, Vaddeswaram, Andhra Pradesh, India.

## Purpose

This repository contains original research code, documentation, verified numerical outputs, and reproducibility metadata for the study. It is designed to provide the materials needed to reproduce the analysis without redistributing third-party copyrighted material.

## Research objective

The study evaluates whether machine learning provides incremental predictive value beyond a persistence baseline for short-term soil-moisture forecasting.

### Models
- Persistence baseline
- Ridge regression
- Random Forest
- Histogram-based Gradient Boosting
- Controlled LSTM robustness baseline

### Forecast horizons
1 h, 6 h, 12 h, and 24 h.

### Validation and uncertainty
Chronological expanding-window validation is used to avoid random temporal leakage. Temporal block bootstrap resampling with 2,000 replicates is used to quantify uncertainty in ML-minus-persistence absolute-error differences.

## Dataset

Source: **AgriDataValue – Environmental Data Useful for Smart Irrigation**  
Zenodo DOI: https://doi.org/10.5281/zenodo.18959383

The study covers two monitoring stations and four station-year datasets. The source dataset contained 22,111 observations; 22,050 were retained after the documented quality-control procedure.

**Raw third-party dataset files are intentionally NOT included in this repository.** The current Zenodo record does not state an explicit redistribution license. Researchers should obtain the source data directly from Zenodo and follow the original repository's terms.

- `CITATION.cff` — citation metadata

## Reproduction

1. Obtain the original source dataset directly from Zenodo.
2. Place local raw files under `data/raw/` without committing them.
3. Install dependencies with `pip install -r requirements.txt`.
4. Run the analysis scripts in `src/` according to their documentation.
5. Compare generated outputs with the verified result tables in `results/`.
