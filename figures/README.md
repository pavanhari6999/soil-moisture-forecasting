# Figures

This directory contains the final manuscript figures. Figures should be generated from committed analysis results rather than edited manually.

The manuscript includes figures covering MAE, RMSE, R2, relative MAE increase, bootstrap delta-MAE, quality-control observations, soil-moisture distributions, temporal coverage, autocorrelation, seasonal persistence, feature ablation, training-window sensitivity, bootstrap block-length sensitivity, complete MAE comparison, LSTM robustness, and ADF/KPSS stationarity.
